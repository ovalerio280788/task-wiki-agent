# Mobile Test Triage

## Goal

Identify failure cause quickly and choose the smallest safe fix.

## Workflow

1. Confirm target repo path from path map.
2. Reproduce with the most targeted test command.
3. Capture failure signature and affected layer (test, app code, env, data).
4. Apply focused fix aligned with existing patterns.
5. Re-run targeted test, then broader relevant suite.
