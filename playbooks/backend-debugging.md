# Backend Debugging

## Goal

Reproduce, isolate, and fix backend issues with minimal change scope.

## Workflow

1. Confirm target repo path from path map.
2. Reproduce with the smallest relevant test command.
3. Identify failing boundary (view, service, selector, serializer, model).
4. Apply focused fix using established repository patterns.
5. Re-run targeted tests, then the nearest related suite.
